# Smoke 接口及接口用例汇总（模板）

> 本文件是索引模板：表头固定 7 列，每条冒烟用例必须登记且 ID 与脚本中的 `test('TC-...')` 一致。

## 1. 说明

- 测试文件：`testcases/<环境>- smoke/xxx.spec.js`，薄挂载文件只 `require`，不重复定义用例。
- 用例 ID：`TC-<模块>[-<子模块>]-NNN`，同一 ID 只在一个维护点出现。
- 校验方式：`npm run cases:check` 报告模式，`npm run cases:check:strict` 作为交付门禁。

## 2. 逐条用例索引

| 测试文件 | 接口 | 用例 | HTTP 状态断言 | Content-Type 断言 | body.code/body.data 断言 | 源码断言（原文） |
|---|---|---|---|---|---|---|
| `testcases/dev- smoke/notice.spec.js` | `GET /api/notice` | `TC-NOTICE-001｜正常获取公告` | 200 | json | `code=200` | `check(response.body.code, '业务码').toBe(200)` |

## 3. 维护说明

- 新增用例：先在脚本写 `test('TC-...')`，再在本文档补一行；顺序与文件内保持一致。
- 删除用例：脚本与索引同一提交删除，避免 `[EXTRA]`。
- 表内包含竖线时转义为 `\|`，避免破坏列结构。
