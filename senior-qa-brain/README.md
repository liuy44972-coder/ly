# senior-qa-brain

资深接口测试工程师助手，围绕 API 契约、业务规则、鉴权、安全、数据一致性和自动化可行性生成结构化测试用例与分析报告。

本 skill 面向 HTTP/HTTPS、REST、GraphQL 等接口测试。

## 功能特性

- **接口契约分析**: 识别方法、路径、参数、鉴权、响应结构和错误码
- **结构化测试用例设计**: 覆盖正常、异常、边界、权限、幂等和业务链路
- **真实行为校准**: 区分文档预期、实际实现、数据问题和待确认事项
- **数据一致性验证**: 设计接口前后数据库状态、持久化和回滚检查
- **风险识别与优先级排序**: 基于影响范围、发生概率和可控性评估风险
- **测试覆盖度分析**: 统计接口、场景、业务码、P0/P1 和数据库验证覆盖率

## 触发词

- 接口测试
- API测试
- 测试用例生成
- 接口风险分析
- 自动化评估
- 数据一致性验证

## 使用方法

1. 在 Trae 中安装此技能
2. 使用接口测试触发词或自然语言描述需求
3. 提供 OpenAPI、PRD、curl、请求/响应示例、接口代码或数据库字段
4. 系统分析接口契约、业务规则、风险和自动化可行性并生成测试用例报告

## 输入示例

```text
根据以下接口描述生成测试用例：

- 请求方法：POST
- 请求路径：/api/example
- Content-Type：application/json
- 请求体：{"name":"test"}
- 成功响应：{"code":200,"data":{"id":"example-id"}}
- 异常响应：以接口实际返回为准
```

## 输出格式

输出为结构化的 Markdown 接口测试报告，包含：
- 项目信息和接口清单
- 测试覆盖概览（接口、场景、业务码、P0/P1、数据库验证）
- 请求/响应 Schema 和真实行为校准结果
- 测试用例明细（表格或分组格式）
- 测试数据生命周期和数据库验证方案
- 风险评估
- 自动化测试建议
- 待确认事项

## 注意事项

- 本工具基于 AI 分析，输出结果需人工审核确认
- 接口分析依赖接口文档、请求示例和响应示例的完整性
- 复杂业务逻辑可能需要额外的领域知识补充
- 自动化评估为建议性质，实际可行性需结合项目技术栈评估
