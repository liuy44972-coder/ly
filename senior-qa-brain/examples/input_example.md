# 输入示例

## 示例1：基于Figma设计稿生成测试用例

### 输入
```
根据这个Figma设计稿生成测试用例：https://www.figma.com/file/example-login-page

设计稿描述：
- 登录页面包含用户名和密码输入框
- 支持邮箱和手机号登录
- 密码要求：6-20位，包含字母和数字
- 忘记密码功能
- 记住我选项
- 登录按钮
- 注册链接
```

### 输出要求
- 生成完整的测试用例报告
- 包含功能测试、边界测试、异常测试
- 评估自动化可行性
- 识别潜在风险

## 示例2：PRD差距分析

### 输入
```
分析以下PRD文档与设计稿的差距：

PRD内容摘要：
1. 用户登录功能
   - 支持用户名/邮箱/手机号登录
   - 密码长度6-12位
   - 登录失败后显示错误提示

设计稿内容：
- 登录页面包含用户名和密码输入框
- 密码框显示"6-20位，包含字母和数字"
- 忘记密码链接
- 记住我复选框
- 第三方登录选项（微信、支付宝）
```

### 输出要求
- 识别PRD与设计稿的差距
- 分析差距影响
- 提供解决方案建议

## 示例3：自动化可行性评估

### 输入
```
评估以下测试场景的Playwright自动化可行性：

场景1：用户登录流程
- 输入用户名和密码
- 点击登录按钮
- 验证登录成功跳转首页

场景2：文件上传功能
- 点击上传按钮
- 选择本地文件
- 验证文件上传成功

场景3：验证码登录
- 输入手机号
- 获取验证码
- 输入验证码
- 点击登录按钮
```

### 输出要求
- 评估每个场景的自动化可行性
- 识别自动化难点
- 提供代码实现建议
